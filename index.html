What is color?

Color, is light that hits an object.

Intesnity

Color Intensity refers to how Vibrant/Bright a color is, knowing this can help when it comes to mixing colors.

Value

Value is how Dark/Light a color is

  1. Tints, are your lightest versions of a color
  2. Midtones, are what you'd percieve as the main version of your color it is seen as the most vibrant.
  3. Shades, darkest versions of a color.

With this in mind it can be easier to know where to put certain colors in their place.
For example, if you we're to paint a sphere you'd know where to put everything and be able to name what it is.

    Tints, Shades, and Midtones
    are all Monochromatic meaning they all come from one color.
    Remember some of this can change based off of RGB and CMYK
    (Red, Green, Blue and Cyan, Magenta, Yellow, Black)
    Mixed together
    Supposedly the theory is that if you were to put all colors together it'd turn black and the opposite white.
    Thats why Value is so important, especially when making new colors.
